# DeepSeek ⇄ PowerShell 本地桥（含手机遥控）

让 **chat.deepseek.com 网页版**真的能在你电脑上执行 PowerShell：DeepSeek 回复里的 PowerShell 代码块会被浏览器扩展抓取，发给本机小桥执行，stdout/stderr/退出码自动填回输入框并发送，DeepSeek 看到结果继续给下一条命令，循环到任务完成。

额外能力：

- **手机遥控**：手机浏览器打开一个页面，就能给 DeepSeek 发消息、开关自动执行、直接执行 PowerShell、查看回复与执行结果。
- **双会话并存**：可以同时开多个 DeepSeek 标签页，同一时刻只有一个在执行（租约互斥），另一个显示「待命」。

## 一、环境要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11 |
| Node.js | 18 以上（`node -v` 能输出版本即可） |
| 浏览器 | Microsoft Edge（Chrome 理论上也行，本文以 Edge 为例） |
| 网络 | 手机遥控需手机与电脑在同一局域网 |

---

## 二、安装（约 2 分钟）

1. 解压整个文件夹到任意位置（路径**不要**含特殊符号，建议 `D:\DeepSeek-PowerShell`）。
2. 双击 **`一键安装.bat`**。它会检查 Node.js、启动本地桥（后台隐藏窗口）、打开扩展目录、Edge 扩展页和 DeepSeek 页面。
3. 在 `edge://extensions/` 页面：打开右下角 **开发人员模式**；点 **加载解压缩的扩展**，选择本文件夹里的 `extension` 目录。
4. 回到 https://chat.deepseek.com/ ，右下角出现 **DeepSeek ⇄ PowerShell** 面板即安装成功。

> 以后每次开机使用前，确认桥在跑：
> - 双击 `bridge\start-bridge.bat`（有窗口，方便看日志）
> - 或双击 `bridge\start-bridge-hidden.vbs`（静默，日志写 `bridge\bridge.log`）
> - 安装时加 `-AutoStart` 可设为开机自启

---

## 三、基本使用

1. 打开 DeepSeek 对话页，确认面板显示 **已连接**（绿点）。
2. 点面板里的 **「发送规则」**。这会发送一条说明，要求 DeepSeek 每次只给一个 PowerShell 代码块。**首次使用强烈建议做这一步。**
3. 正常提问，例如：`看看我电脑上 Node 和 Python 的版本，再列出当前目录的文件。`
4. 之后全自动：DeepSeek 出命令 → 本机执行 → 输出自动发回 → 它继续。

> 「发消息后自动执行」是安全设计：只有你手动发过消息（回车或点发送），或点了「发送规则 / 立即检查」，才会开始执行。刷新页面、切换会话、翻看历史都不会误跑旧命令。

### 面板控件

| 控件 | 作用 |
| --- | --- |
| 绿点 / 红点 | 本地桥是否连通 |
| 状态灰字 | 实时显示当前进度（等待发消息 / 等待回复稳定 / 正在生成 / 没有代码块 / 已执行过…） |
| 自动执行 | 总开关（关掉后只显示，不执行、不发送） |
| 发送规则 | 发一条「每次只给一个 PowerShell 代码块」的引导消息 |
| 立即检查 | 立刻重新扫描最后一条回复（调试用） |
| 重置计数 | 把「已执行 N / 上限 40」清零 |
| 刷新 | 重新加载扩展 + 刷新当前聊天页（改完扩展代码后点它） |
| ⚙ | 设置本地桥地址、**手机遥控令牌** |
| 浏览器工具栏图标 | 点击 = 开/关自动执行 |

## 四、手机遥控

### 4.1 开启

启动桥后，桥窗口（或 bridge.log）会打印类似：

    手机遥控（同一局域网打开）:
      http://192.168.1.100:8787/remote?token=xxxxxxxxxxx

手机连同一 WiFi，浏览器打开该地址即可。

### 4.2 手机页面功能

- 发给 DeepSeek：输入文字直接发到当前聊天页
- 发送规则：发送引导消息
- 自动执行：开关
- 立即检查 / 重置计数
- 直接执行 PowerShell：绕过 DeepSeek 直接在本机执行并看结果
- DeepSeek 最新回复：聊天式列表，最新在底部
  - 纯文字的最终回答：粗体；最新一条完整，历史只显示两行可展开
  - 含代码的过程消息：灰色细体，只显示文字；点开看代码、成败、退出码、耗时、输出
- 状态：桥/扩展是否在线、已执行次数、工作目录
- 最近日志
### 4.3 令牌

- 首次启动桥时 remoteToken 为空，桥会自动生成随机 token 并写回 config.json。
- 手机地址里的 ?token= 必须与之一致。
- 电脑端扩展会自动通过 /api/pair（仅限本机 127.0.0.1）取得 token，无需手动填写。
- 手动更换：改 config.json 的 remoteToken 后重启桥。

### 4.4 手机打不开页面？

- 确认手机和电脑在同一 WiFi（同一网段）。
- Windows 防火墙首次会询问是否允许 Node.js 访问网络，选允许。若没弹或点错，用管理员 PowerShell 执行：

    New-NetFirewallRule -DisplayName "DeepSeek Bridge 8787" -Direction Inbound -Protocol TCP -LocalPort 8787 -Action Allow

- 电脑有多个网卡时，桥会打印所有可用地址，挑与手机同网段的那个。

## 五、双会话

- 可以同时打开多个 chat.deepseek.com 标签页。
- 用 chrome.storage 里的租约（15 秒 TTL、5 秒续期）保证同一时刻只有一个会话在执行。
- 你在哪个页面手动发消息，那个页面就抢占执行权；另一个显示「待命（另一会话在执行）」。
- 手机遥控指令优先投给持有租约的会话。
- 当前会话关闭自动执行或达到上限后，租约释放，另一个自动接手。

## 八、常见问题

**面板不出现？**
- 确认扩展已加载且无报错（edge://extensions/ 里看「错误」）。
- 确认页面是 https://chat.deepseek.com/ 。
- 刷新页面（扩展只在页面加载时注入）。

**面板红点「未连接」但桥明明在跑？**
- 多半是扩展刷新过、但网页没刷新：按 F5 刷新 DeepSeek 页面。
- 还不行就在 edge://extensions/ 里移除扩展，重新「加载解压缩的扩展」，再 F5。

**改完扩展代码不生效？**
- 点面板「刷新」，或去 edge://extensions/ 点重新加载，然后 F5 聊天页。

**命令失败后整个循环卡住了？**
- 旧版本存在此问题，现已修复：命令被拦截或报错时，扩展会自动把错误发回给 DeepSeek，让它自行调整。
- 如果仍卡住，检查输入框是否有草稿（扩展不会覆盖你的草稿），清空后自动继续。

**手机页面一直显示「扩展离线」？**
- 桥没收到扩展轮询。检查扩展是否已重新加载、聊天页是否已刷新，然后手机刷新页面。

**手机端回复里出现「复制 / 下载」字样？**
- 旧版本问题，现已修复：上报前会剔除按钮类元素。

**桥重启后手机历史清空？**
- 回复与执行记录只存在桥的内存里，重启即清空，属正常。

**怎么彻底停掉桥？**
- 双击 bridge/stop-bridge.bat（若装了守护进程，先结束 supervise 再停 node）。

## 九、目录结构

    DeepSeek-PowerShell-插件/
    ├─ 一键安装.bat              安装助手
    ├─ install.ps1               安装脚本
    ├─ README.md                 本文档
    ├─ bridge/
    │  ├─ server.js              本地桥（Node，无第三方依赖）
    │  ├─ remote.html            手机遥控页面

    │  ├─ start-bridge.bat       前台启动
    │  ├─ start-bridge-hidden.vbs 静默启动

       ├─ background.js          后台：代访问本地桥、轮询手机指令

       ├─ core.js                纯函数：语言识别、结果格式化
       └─ icons/                 图标
